# AI CV & Internship Assistant

AI destekli CV analiz ve staj başvuru asistanı.

## Proje Amacı

Bu proje, kullanıcıların CV dosyalarını ve GitHub profillerini analiz ederek staj başvuruları için kişiselleştirilmiş öneriler, eksik teknoloji analizi, staj maili ve LinkedIn mesajı üretmeyi amaçlar.

## Kullanılan Teknolojiler

- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- OpenAI API
- HTML / CSS / JavaScript

## Proje Durumu

Geliştirme aşamasında.
